# 単語レイド（試作）引き継ぎメモ

英単語タイピング × クラス協力バトルのWebアプリ試作。
このファイルと `index.html` を渡せば、別のClaude（または人）が続きから開発できるようにまとめています。

- 最終更新：2026-11-16
- ファイル構成：`index.html`（1ファイルで完結）、`README.md`（この文書）、`sample_words.csv`（単語CSVの見本）

---

## 1. コンセプト

- 寿司打のような「流れる」系ではなく、**英単語で攻撃してモンスターを倒すレイドバトル**。
- 授業で使える **Kahoot風のクラス機能**：先生が部屋をつくり、生徒が4けたコードで参加、全員のダメージで1体のボスを削る協力戦＋個人ランキング。
- 終わったあとの **振り返り** と **先生向けCSV** を重視。

## 2. 遊び方（現在の仕様）

| 項目 | 内容 |
|---|---|
| 答え方 | 「英語→日本語」「日本語→英語」の2モード |
| 単語セット | 中学の基本（B01〜）、経済・ビジネス（E01〜）、TOEIC頻出（T01〜）、自分の単語（C01〜） |
| 制限時間 | 60 / 90 / 120 秒 |
| 1問の時間 | 約13秒（コンボで短くなり最短9秒） |
| ヒント | 1問の時間の65%が過ぎるとKahoot風の4択（▲◆●■、1〜4キー）が出る |
| ダメージ | 打って正解：100＋120×残り時間割合、コンボ倍率（最大2倍）。4択正解：半分・コンボ増えない |
| 失敗 | 時間切れ・4択ミス・Escでとばす → コンボリセット、まちがいとして記録 |
| ボスHP | 1200 × 参加人数 × (1 + 0.35 × 何体目) |
| ひとりモード | CPUの仲間3人（リン・ソウタ・ミオ）と協力 |
| 日本語入力 | IME確定で判定。ひらがな・カタカナも正規化して判定（意味の候補を `/` 区切りで複数登録） |

## 3. クラス機能

- 先生：「部屋をつくる」→ 4けたコード表示 → 「スタート」で全員同時開始。
- 先生画面：ボスHP、ダメージランキング、表彰台、**まちがえやすかった単語の表**、**生徒ごとの結果の表**。
- 先生が「自分の単語」を選んでいれば、その単語リスト（重み付き）を生徒全員に配信（最大およそ60語）。
- 途中参加は不可。

### 通信の仕組み（重要）

現在は **claude.ai のアーティファクト専用機能** を使っています。

- `claude.use("room")`：同じページを開いている人どうしのリアルタイム通信
  - `join("raid-<コード>")` で部屋に参加
  - 生徒は presence に `{role:"player", nick, dmg, combo, st, sum, state}` を載せる
    - `st`：`{ "<単語番号>": [出題回数, まちがい回数, 4択正解回数] }`
    - `sum`：`[打って正解, 4択正解, まちがい, 最大コンボ]`
  - 先生は presence `{role:"host"}`、トピック `start` で `{mode, deck, secs, epoch, words?}` を送信
- `claude.use("downloads")`：CSVの保存

**制約**：claude.ai 上で、持ち主と同じ組織のメンバーか招待された人しか部屋に入れません。公開リンクで開いた人は接続不可。
claude.ai の外（GitHub Pages、ローカル等）では両方とも `null` になり、クラス機能とCSV保存ボタンは自動で無効化されます（ひとりモードは動く）。

## 4. CSV形式

### 単語CSV（読み込み用）
```
番号,英単語,意味
C01,revenue,収益/売上/しゅうえき
C02,profit,利益/りえき
```
- 番号は省略可（自動で C01〜 を付与）。
- 意味は `/` 区切りで複数正解。ひらがなでも正解にしたい場合はひらがなも並べる。
- 1行目に「英単語」を含む行はヘッダーとして読み飛ばす。

### 番号指定
`E01-E10, T03, T07` のように入力すると、その単語でセットを作る。

### 先生向け：単語別CSV（`単語別_<コード>_<日付>.csv`）
```
番号,英単語,意味,まちがえやすさ,まちがえた人数,答えた人数,まちがい回数,4択で正解,出題回数,まちがえた生徒
```
- まちがえやすさ ＝（まちがい＋4択×0.5）÷ 出題回数
- **このCSVを読み込み直すと、そのまま次回の問題になる**
  - まちがえやすさに応じて出題回数を最大4倍に重み付け（チェックで無効化可）
  - 「まちがえやすさ20/40/60%以上」で絞り込み可

### 先生向け：生徒別CSV（`生徒別_<コード>_<日付>.csv`）
```
名前,ダメージ,打って正解,4択で正解,まちがい・時間切れ,出題数,打って正解した割合,最大コンボ,まちがえた単語（番号）,まちがえた単語
```
- 問題としては読み込めない（読み込もうとすると案内メッセージを表示）。

### 生徒・ひとり用：まちがえた単語CSV
```
番号,英単語,意味,まちがえた回数
```
- 読み込み直すと、まちがえた回数に応じて重み付け出題。

## 5. コードの構成（index.html）

1つの `<script>` ブロック内、主な関数：

| 区分 | 関数 |
|---|---|
| 単語データ | `DECKS`、`ALL`（番号→単語のMap）、`parseCSV`、`setCustom`、`weighted` |
| ゲーム | `startGame`、`next`、`loop`、`openChoices`、`check`、`hit`、`fail`、`end`、`track` |
| パーティ/ボス | `party`、`boss`、`arena`、`refresh`、`rankHTML`、`podium` |
| クラス | `pub`、`valid`、`collect`、`classAgg`、`stuRows`、`renderAgg`、`renderStu`、`hostTick` |
| 出力 | `toCSV`、`aggCSV`、`stuCSV`、`save`、`copyOut` |

単語1件は配列 `[英単語, "意味1|意味2|...", 番号]`、重みは配列のプロパティ `wt`。

## 6. 試作で見送ったこと・既知の課題

- 振り返りテストのPDF生成：いったん見送り（CSV中心に）。
- 本番の授業で使うには、通信部分を claude.ai 専用機能から置き換える必要がある：
  - **案A**：GitHub Pages ＋ Firebase Realtime Database（URLを知っていれば誰でも参加可）
  - **案B**：ターミナルで動く Node.js サーバー（同じWi-Fi内のみ、テスト向け）
  - 置き換えるのは `claude.use("room")` と `claude.use("downloads")` の部分だけ。ゲーム本体はそのまま使える。
- 実機の複数人テストは未実施（先生側集計はダミーの生徒データでのみ確認済み）。
- 日本語の意味の言い換え（登録外の表現）は不正解になる。
